# Hato AI Lab

Laboratorio de desarrollo humano–IA.

Un espacio para experimentar, construir y documentar herramientas de software mediante la colaboración entre desarrolladores e inteligencia artificial, utilizando recursos abiertos y procurando mantener el conocimiento del proyecto portable, accesible y persistente.

## Propósito

Hato AI Lab nace como un laboratorio práctico para explorar nuevas formas de trabajar entre desarrolladores e inteligencia artificial.

El proyecto parte de una idea sencilla:

> El conocimiento de un proyecto no debería depender de una conversación, una cuenta, una plataforma o una inteligencia artificial determinada.

Por ello, el repositorio forma parte esencial del proyecto y funciona como su **memoria técnica, conceptual e histórica**.

## Memoria del proyecto

El repositorio conservará progresivamente:

- la historia del proyecto;
- las ideas y conceptos que lo originan;
- las decisiones de diseño;
- los experimentos realizados;
- los protocolos de colaboración humano–IA;
- la arquitectura y especificaciones;
- el código;
- las pruebas;
- los resultados y aprendizajes.

La intención es que una persona o una IA que llegue posteriormente al proyecto pueda estudiar su contenido y reconstruir su contexto sin depender de conversaciones anteriores.

## Primer laboratorio

El primer campo de experimentación es **Hato**, un sistema para la gestión y análisis de una explotación ganadera.

Hato permite utilizar un dominio real para investigar problemas de modelado, métricas, composición de información, reglas, indicadores y automatización.

A partir de estas necesidades surge el desarrollo de un **motor de métricas y herramientas asociadas**, que constituye uno de los primeros componentes experimentales del laboratorio.

## Filosofía

Hato AI Lab busca demostrar que es posible construir proyectos tecnológicos complejos utilizando una combinación de:

- conocimiento del desarrollador;
- inteligencia artificial;
- software libre y recursos abiertos;
- documentación estructurada;
- control de versiones;
- experimentación;
- colaboración iterativa.

La IA participa como colaborador y herramienta de construcción.

El desarrollador mantiene la dirección, las decisiones y el control del proyecto.

Git conserva la evolución.

La documentación conserva el conocimiento.

## Principio fundamental

> **La IA puede ayudar a construir el proyecto, pero la memoria del proyecto pertenece al proyecto.**

## Estado actual

**Etapa:** Laboratorio conceptual y experimental.

**Primer experimento:** establecer el repositorio como memoria persistente del proyecto y desarrollar una metodología de colaboración humano–IA alrededor de él.
