# MEMORY CHECKPOINT — MC-2026-08-21-001

## Etapa
Inventario y diseño de captura zootécnica.

## Estado
**CONCLUIDO — DISEÑO PUBLICADO.**

## Decisión
Hato debe construirse bajo la cadena:

`CAPTURA → HISTORIA → MOTOR DE MÉTRICAS → INDICADORES → PANEL`

El hecho de que el Motor pueda expresar una métrica no significa que Hato ya tenga los datos necesarios para calcularla. La captura histórica y el Motor son componentes vinculados.

## Estado verificado
La base existente ya incluye:

- `Finca` y `Potrero` con contexto multi-finca y geometría.
- `Animal` con identidad, nacimiento, genealogía, categoría y estado.
- `PesajeAnimal` para series históricas de peso.
- `EventoSalud` para vacunación, desparasitación, enfermedad/diagnóstico, tratamiento, lesión, cirugía, examen y consulta, además de producto, dosis y veterinario.
- `MovimientoAnimal` para historial de entrada/salida y potrero.
- procedencia, adquisiciones, genética y documentos.
- `apps/produccion` con `Metrica` y `VariableMetrica` para definiciones declarativas.

## Vacíos principales
Antes de habilitar métricas zootécnicas avanzadas se deben diseñar:

1. Reproducción.
2. Lactancia/producción de leche.
3. Historia clínica sanitaria ampliada.
4. Eventos históricos explícitos de nacimiento, muerte y destete cuando sean necesarios para trazabilidad y cálculo.
5. Captura adicional de pastoreo solo cuando una métrica seleccionada la requiera.

## Fuentes de referencia
- FAO/FAOSTAT: metodología de LSU y datos ganaderos.
- ICAR: estándares de registro animal, leche y reproducción/fertilidad.
- Ciencia Agropecuaria 2025: inventario científico de índices zootécnicos y productividad en sistemas doble propósito.
- AGROVOC: normalización terminológica.

Las fuentes son base de investigación y normalización; no se copian fórmulas automáticamente al Motor.

## Regla técnica
No inventar datos. No declarar métricas oficiales sin definición y fuente. No asumir fórmulas universales cuando la metodología depende de país, especie o sistema. Reutilizar modelos existentes antes de crear entidades nuevas.
