## 5. Problema detectado en Admin

Al abrir el cambio de Finca 1 apareció:

`AttributeError: 'Finca' object has no attribute 'finca'`

El traceback indicó temporalmente `apps/core/admin.py`, línea 105, dentro de `has_delete_permission`, ejecutando `obj.finca`.

Posteriormente se mostró el `FincaAdmin` actual y se verificó que ese código ya utiliza correctamente:

`usuario_puede_acceder_finca(request, obj)`

en `has_view_permission()` y `has_change_permission()`, y que `has_delete_permission()` devuelve `False` para usuarios normales.

Por tanto, existe una discrepancia entre el código que produjo el traceback y el contenido actual del `FincaAdmin` mostrado durante la sesión. **No se debe modificar el modelo ni crear nuevas migraciones por este error hasta identificar la versión exacta del `admin.py` que está ejecutando Django.**

## 6. Lección metodológica registrada

El repositorio es la fuente de verdad. Ante una discrepancia entre traceback y fuente mostrado por el desarrollador, la secuencia correcta es:

`FUENTE REAL -> VERSION EJECUTADA -> EVIDENCIA -> DIAGNÓSTICO -> CAMBIO`

No se deben proponer modificaciones basadas únicamente en una versión supuesta del archivo.

En particular, no se debe asumir que todas las apariciones de `obj.finca` tienen el mismo significado: en `PotreroAdmin` y `UsuarioFincaAdmin` puede ser correcto, mientras que en `FincaAdmin` el objeto `obj` ya es una `Finca`.
