# Home / Portal Central

Actualización del portal principal de Hato AI Lab.

- La raíz `/` queda destinada al Home central del sistema.
- El Home muestra la finca activa y accesos a las funciones existentes.
- Las métricas se administran y prueban desde Producción.
- El selector de finca determina el contexto operativo de las páginas que usan `obtener_finca_activa()`.
